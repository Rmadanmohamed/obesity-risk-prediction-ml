# Obesity Risk Prediction ML

## Overview and problem statement

Explore preprocessing of structured health and lifestyle records for obesity risk classification. This repository is an incomplete modeling experiment rather than a trained prediction system.

## Technology stack and prerequisites

- Python 3 (exact version not specified); a Python notebook environment is required.
- Declared dependencies in [requirements.txt](requirements.txt): matplotlib, numpy, pandas, scikit-learn, seaborn. All are unpinned.
- Google Colab or local Jupyter; local Jupyter must be installed separately. No GPU or external service is explicitly required.

## Project structure

- [Notebook](notebooks/obesity-risk-prediction.ipynb) — experiment source.
- [requirements.txt](requirements.txt) — dependency list.
- [LICENSE](LICENSE) — repository license; dataset rights are separate.

## Dataset and preprocessing

`train.csv` and `test.csv` under `/content/`; neither data source nor license is specified. The notebook explores columns and encodes categorical values; it scales `Age` and `Weight`. The target and split are not established in executable code.

## Model and workflow

The notebook imports logistic regression, random forest, gradient boosting, decision tree, KNN, Gaussian naive Bayes and SVC but does not fit them.

## Installation and execution

Clone the repository and open it:

```bash
git clone https://github.com/Rmadanmohamed/obesity-risk-prediction-ml.git
cd obesity-risk-prediction-ml
python -m venv .venv
```

Activate the environment on Linux/macOS with `source .venv/bin/activate`, or on Windows PowerShell with `.venv\Scripts\Activate.ps1`.

```bash
python -m pip install -r requirements.txt
python -m pip install jupyter
jupyter notebook notebooks/obesity-risk-prediction.ipynb
```

Alternatively, open the notebook in Colab and supply the required data. The notebooks use Colab-style absolute paths; for local use, update paths in a local working copy to point to your data. No exact reproducible dependency lock or supported Python version is supplied.
